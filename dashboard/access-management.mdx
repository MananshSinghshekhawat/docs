Access Management is where you control **who can enter which door and when**. SUITEe provides both automatic and manual access control, giving you complete flexibility while keeping your property secure.

## How access works

SUITEe provides two types of access management:

| Type | How It Works |
| :--- | :--- |
| **Automatic Access** | Created automatically from PMS reservations. A digital key or PIN code is generated at check-in time and expires at check-out. |
| **Manual Access** | Staff can manually create, modify, or revoke access for specific people at any time. |

---

## Access types

| Access Type | Who Gets It | Typical Duration |
| :--- | :--- | :--- |
| **Guest Access** | Hotel guests (automatic from reservations) | Check-in to check-out |
| **Staff Access** | Hotel employees | Ongoing (specific hours or permanent) |
| **Maintenance Access** | Repair workers, technicians | Temporary (hours or days) |
| **Cleaning Crew Access** | Housekeeping staff | Specific hours (e.g., 8 AM – 4 PM) |

<Info>
  Guest access includes both their **room door** and the **building entrance**. Staff access can be configured for specific areas based on their role.
</Info>

## Multi-level access control

SUITEe can manage access for different areas of your property, not just room doors:

| Access Level | Example |
| :--- | :--- |
| **Main building entrance** | The front door or lobby entry |
| **Floor/hallway doors** | Access to specific floors |
| **Room doors** | The guest's individual room |
| **Amenity areas** | Spa, gym, pool, parking garage, etc. |

A guest might have access to the building entrance, their floor, their room, and the gym — but not the spa or other guest rooms. This is all configurable per reservation or per access grant.

## How PIN codes work

PIN codes are numeric codes that guests enter on the smart lock keypad to open doors.

<Steps>
  <Step title="System generates a unique PIN">
    When a reservation is synced from the PMS, SUITEe automatically generates a **unique PIN code** for that guest.
  </Step>

  <Step title="PIN is sent to the guest">
    The PIN is included in the guest's **check-in instructions** sent via email or SMS before arrival.
  </Step>

  <Step title="PIN is valid for the stay duration">
    The PIN only works during the guest's stay — from check-in time to check-out time.
  </Step>

  <Step title="PIN expires automatically">
    At check-out time, the PIN **automatically stops working**. No staff action needed.
  </Step>
</Steps>

<Tip>
  If a guest forgets their PIN or needs a new one, staff can **generate a new PIN code** from the dashboard at any time. The old PIN is immediately invalidated.
</Tip>

## How mobile keys work

Mobile keys let guests unlock doors using their **smartphone** — no app download required.

<Steps>
  <Step title="Guest receives a link">
    The guest receives a link to the **Guest Web App** via email or SMS.
  </Step>

  <Step title="Guest opens the web app">
    The guest opens the link in their phone's browser. No app store download needed.
  </Step>

  <Step title="Mobile key is activated">
    At check-in time, the mobile key becomes active. The guest can now unlock their door by tapping a button in the web app.
  </Step>

  <Step title="Mobile key deactivates at check-out">
    At check-out time, the mobile key is automatically deactivated.
  </Step>
</Steps>

## Managing access from the dashboard

Staff can perform the following access management actions:

| Action | How |
| :--- | :--- |
| **View all active access** | See who currently has access to which doors |
| **Generate new PIN** | Create a fresh PIN for a guest who lost theirs |
| **Revoke access** | Immediately disable someone's access (for emergencies) |
| **Grant temporary access** | Give maintenance or cleaning staff time-limited access |
| **View access logs** | See who opened which door and when (audit trail) |

</Warning>

## Access logs (audit trail)

Every door opening is logged by SUITEe, creating a complete **audit trail**:

- **Who** opened the door (guest name, staff member, or access code used)
- **When** it was opened (date and time)
- **Which door** was accessed
- **How** it was opened (mobile key, PIN code, or manual key)

<Info>
  Access logs are invaluable for security purposes. If there's ever a question about who entered a room and when, the audit trail provides a definitive answer.
</Info>
